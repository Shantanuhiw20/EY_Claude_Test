# Closing - Feedback, Testimonials + What's Next

Day 2.

You just finished the hackathon, your second persona, built and deployed. This is the close.

Two days ago you had not used this tool. Now look at what you built: a working, deployed diagnostic tool, end to end.

## What You Built

- A short `CLAUDE.md`: your own context and house rules, the same file for every persona you ever build.
- An AP Finance Persona file (`personas/ap-persona.md`) that makes Claude think like an AP expert.
- Four small skills: data-checklist, benchmark-interpreter, template-filler, file-reader.
- A Reviewer agent in `.claude/agents/`: a hard read on a draft report or a question set before it goes to a client, and the one that sharpened your diagnostic questions before they went live.
- A deployed AP diagnostic chatbot: chat-based intake, file upload, a benchmarked report, code on your own GitHub repo, live on Vercel. And if you went further, every interview saved to a database and resumable from its own link.
- A second persona of your own (AR, R2R, FP&A, or a real client) built with `/build-persona` and adapted from the first, also on GitHub and live on Vercel.

That is not "trying AI." That is building the diagnostic yourself, and watching it happen in two days.

## Keep It Alive (the part that matters)

Most people go quiet after a bootcamp. Don't be most people.

This week:
- Swap the sample data in this repo for your own AP data collection template, benchmark set, and a reference report. The file shapes stay the same.
- Open Claude once a day for one real task. Small is fine.
- Add one line to your AP Finance Persona file each time you notice the chatbot missing context.

This month:
- Pick one other practice area (AR, R2R, FP&A, or a specific client) and fully build out its persona, past the hackathon sketch.
- Show your deployed chatbot to one real colleague or client-facing partner. Show them, don't tell them.

Where this goes next: the report your app produces is a document someone reads and then acts on. The next step for a client is a report they can talk to, ask "what if" of, and that nudges them when a number needs attention. That is decision intelligence, and it starts from exactly the pattern you built this week.
